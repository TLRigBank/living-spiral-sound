Healing / 432-branded content may keep that *intent* in the track card. Do not print a false Hz claim on the release notes.

## Session lock procedure

1. Measure ding and A4 from a 20 s isolated take.
2. Set the DAW reference to that A4.
3. Tune pads, piano, and bass to the pan.
4. Write both Hz numbers on the session card.
