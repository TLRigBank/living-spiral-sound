# Recording spec

Use this when recapturing a take meant for a release mix.

## Capture

- 24-bit, 48 kHz (or 96 kHz if the room is quiet and disk is cheap)
- Two mics: overhead 8–12 in above the pan, room 4–6 ft
- Peak ceiling **−12 dBTP** — no 0 dBFS hits
- 20–30 s of isolated ding + A + D4 at the top of the file for tuning lock

## Room

- Soft surfaces if possible
- Keep the overhead off-axis from slapback walls
- Note temperature. Steel goes sharp in heat. Phoenix sessions will read high vs 440.

## Naming

```
YYYY-MM-DD_instrument_take-NN_source.wav
YYYY-MM-DD_instrument_take-NN_oh.wav
YYYY-MM-DD_instrument_take-NN_room.wav
```

## Do not

- Record only mono AAC at 71 kb/s for masters
- Limit the take on the way in
- Tune other instruments to a 432 preset if the pan on the day is 442
